# AI 健身教練

用手機相機辨識身體姿勢、自動計算運動次數的網頁 App（PWA）。不用安裝、不用註冊。
所有畫面與姿勢資料只在你的手機上處理，不會上傳。

線上版：https://alanchen75.github.io/ai-fitness-coach/

## 這是什麼、適合誰

- **在家自主訓練的人**：手機架在旁邊，邊做邊聽語音報數，做完可以回顧每一組的紀錄
- **健身教練、瑜伽老師**：把常教的動作做成可計數的動作，讓學員回家自己練
- **想把手機變成電視健身鏡的人**：手機橫放、投影到電視，站在客廳看大字次數

## 可以做什麼

- 24 個動作，分成初階、中階、進階、器械四類，每個動作附解剖風格的示範動畫
- 21 個動作可自動計數：18 個徒手動作，加上滑輪下拉、坐姿划船、器械划船
- 坐姿胸推、肩推機、腿部推蹬目前只有示範，不計數
- 計數採保守原則：寧可漏算也不亂算；動作不完整或追蹤中斷時，標為「待確認」而不是直接算進去
- 入位引導：檢查該動作需要的身體部位都在畫面內，才開始計數
- 語音報數
- 電視模式：手機橫放時，左側顯示大字次數與狀態，右側顯示相機畫面；適合用手機的「投放螢幕」鏡像到電視
- 訓練回顧：每組次數、追蹤品質，可匯出完整 JSON（含逐幀姿勢資料，用來校準門檻）

## 使用前要知道的限制

- **一次只能一個人**入鏡，背景有其他人可能干擾
- **只在 Android 手機的 Chrome 實際測過**；iPhone Safari 尚未驗證
- **計數門檻大多還沒經過實機校準**：原地踏步抬腿已用手機實測資料校準；三個器械動作用健身房實拍影片離線校準；其餘動作的門檻是依動作原理設定的初版（規則版本 `-v0.1`），可能需要依實際使用調整
- 相機擺放會影響準確度，每個動作的步驟說明第一條是擺放建議（多數動作要側面拍）
- 本 App 只做次數與姿勢輔助，不是醫療或復健建議；有傷病請先諮詢專業人員

## 怎麼用

1. 用 Android 手機的 Chrome 開啟上面的線上版網址，可選擇「加到主畫面」
2. 選一個動作，看完示範後按「我知道了，開始」，允許使用相機
3. 依提示站好位置，入位檢查通過後開始做
4. 做完按「結束一組」或「結束訓練並儲存」，到回顧頁查看

想投影到電視：開啟訓練頁底部的「電視」開關，把手機橫放，再用手機的「投放螢幕」連到電視。

## 資料與隱私

- 相機畫面只在瀏覽器內處理，姿勢模型檔隨 App 一起下載，執行時不呼叫任何外部服務
- 訓練紀錄存在手機瀏覽器的本機儲存（IndexedDB 與 OPFS），刪除 App 資料就會一起刪除
- 沒有帳號、沒有分析追蹤、沒有廣告

## 自己部署

這是純靜態網站，任何靜態主機都能放（本專案用 GitHub Pages）。

```bash
npm install
npm run build        # 產出 dist/
npm test             # 單元與回歸測試（vitest）
npm run test:e2e     # 端對端測試（Playwright，使用假相機）
```

把 `dist/` 的內容放到靜態主機即可。相機需要 HTTPS（或 localhost）才能開啟。
改版時請升級 `public/sw.js` 裡的 `CACHE_NAME`，否則已安裝的使用者會繼續看到舊版。

## 專案結構

- `src/engine/`：計數狀態機（保守計數、待確認判定）
- `src/exercises/`：動作清單、計數門檻、姿勢指標
- `src/framing.ts`：入位檢查
- `tests/fixtures/`：真實影片與手機實測的指標序列，作為回歸測試
- `tools/figure-gif/`：示範動畫的產生工具（`npm run figures`）
- `docs/ITERATION*-TASK.md`：每一輪改版的規格與測試矩陣
